# U60 academic image acceptance

This branch preserves the validated Android implementation. Candidate illustrations are not approved for classroom use until independent scientific, bilingual editorial, licensing and device checks are recorded.

Required checks for each standalone PNG:
- Identify the exact organism, view and biological stage.
- Confirm all anatomical landmarks and leader-line endpoints against an authoritative source.
- Verify English and Tamil terminology.
- Record source URL, author, redistribution permission, reviewer and approval date.
- Require a genuine high-resolution image; reject crops enlarged from a small composite.
- Run same-commit Kotlin, Android and offline screenshot tests at normal and double Tamil font scale.

This document does not approve any current image.
