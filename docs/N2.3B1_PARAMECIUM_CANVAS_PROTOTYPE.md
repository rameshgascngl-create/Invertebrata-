## Delivered

The Paramecium A5 chapter now has an original Android Jetpack Compose
Canvas specimen schematic, placed AFTER the existing bilingual lesson and
A5 questions. It is neither an HTML page nor a WebView, an SVG viewer,
a photograph or a tracing/copy of a published figure.

The first plate is external-cilia only. Its five candidate structures have
stable IDs already defined in the N2.3A scientific specification:
pellicle, somatic-cilia, oral-groove, cytoproct, trichocysts.

The prototype draws an original contour, contour-following cilia, a
provisional oral-groove curve, a candidate cytoproct opening, and cortical
trichocyst marks. This is a SCHEMATIC, with deliberate pedagogical
exaggeration. Proportions, placement and structural topology need
expert verification against a species-specific microscope/atlas reference.

The Canvas supports direct tap-to-highlight on provisional named
landmarks. Each feature is also exposed through a dedicated large
48dp-minimum Compose button with English–Tamil text, and the selected
label appears separately for accessibility. No network dependency,
permission, speech engine or state schema change was introduced.

The prototype uses its own separately named normalized hit regions. It
NEVER overwrites the N2.3A "pending-geometry" or "pending-touch" keys,
nor does it fabricate a review record or assign ACCEPTED status.
The existing strict AnatomySpecificationContract continues to reject
an accepted plate with any pending geometry.

## Academic basis, and clear limitations

External form, the ciliary covering and oral groove of Paramecium caudatum
are described in university zoology study resources, including:

- Uttarakhand Open University, BSCZO-104 Practical Zoology, around page 293:
  https://uou.ac.in/sites/default/files/slm/BSCZO-104.pdf
- Vardhman Mahaveer Open University, MZO-05 (Paramecium):
  https://assets.vmou.ac.in/MZO05.pdf
- Scientific review of Paramecium as model organism:
  https://pmc.ncbi.nlm.nih.gov/articles/PMC10143506/
- Primary research on oral apparatus ultrastructure:
  https://pmc.ncbi.nlm.nih.gov/articles/PMC2109358/

These are reading/provenance pointers, NOT documented independent approval
of the new Canvas positions. In particular, a scientifically competent
reviewer must check anterior/posterior orientation, trichocyst localization,
oral-groove topology, cytoproct placement, cilia outlines, label endpoints
and Tamil terminology for the actual reference species.
